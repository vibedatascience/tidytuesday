## Reproduce

```sh
python -m pip install -r requirements.txt
python 2026/2026-09-08/20260908.py
```

Each week's folder contains its chart, plotting code, data and a short README.

Design references come from [Nicola Rennie's TidyTuesday archive](https://github.com/nrennie/tidytuesday), using other weeks' work as inspiration. Charts are original, with references credited in the weekly README. Headlines state the finding directly.
