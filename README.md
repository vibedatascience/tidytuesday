## Reproduce

Python 3.9–3.12:

```sh
python -m pip install -r requirements.txt
python 2026/2026-09-08/20260908.py
```

Each weekly script creates the single PNG beside it. Most inputs are bundled as gzip-compressed CSV files; the lyrics analysis fetches its source data when run. Each weekly README explains the calculation and links to the original data provider.

To rebuild all weeks:

```sh
for script in 2026/*/*.py; do
  python "$script"
done
```

Data: [TidyTuesday / Data Science Learning Community](https://github.com/rfordatascience/tidytuesday), with original sources credited in each week's README. Charts and code: vibedatascience.
